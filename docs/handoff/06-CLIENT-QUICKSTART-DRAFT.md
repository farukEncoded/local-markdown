# Local Markdown: client guide draft

This guide describes the planned app. Update its button names and screenshots after testing the finished Windows installer.

## Install once

Open the Local Markdown setup file supplied to you and complete installation. Then open **Local Markdown** from the Start menu or desktop shortcut.

You should not need to install Python, Office readers, or other tools. The completed app should work without an internet connection.

## Convert documents

1. Click **Add files** and choose one or several documents.
2. Click **Convert**.
3. Select a result to preview its Markdown.
4. Click **Save Markdown** to save one result, or **Save all as ZIP** for the batch.
5. Use the saved file in the tool of your choice.

Use **Copy Markdown** if you prefer to paste the text. Use **Stop** to cancel current work.

## Check results

Review any scan-reading warning, particularly names and numbers. Tables, diagrams, and complex layouts may need checking. If a PDF produces poor text, select it and use **Try scan reading**.

If the app reports a locked file, save an unlocked copy and try again. A failed file does not stop the other documents in a batch.

## Clear app history

Save any results you want to keep. Then click **Clear history** and confirm.

This removes the app's history and stored previews. Your original documents and Markdown/ZIP files you already saved remain on your computer.
